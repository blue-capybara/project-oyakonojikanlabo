## プレビュー修正と停止理由

続いて、Gutenbergの編集用REST `link`対応を含む`ojl-series-preview.php`、`preview-endpoint.php`、`preview-admin-ui.php`を順番に反映しました。各ファイルは本番PHPで構文確認後、ハッシュ一致を条件に置換しました。

管理画面へログイン後、新しい検証用連載だけを作成し、Gutenbergでタイトル・紹介文・予定総回数を入力して下書き保存しました。この保存時、旧Easy_Seriesから次の2件が記録されました。

- `Undefined array key "easy-series-id"`
- `Undefined array key "easy-series-number"`

原因は旧`wp-content/plugins/easy-series/easy-series.php`の`Easy_Series::save_post()`です。全投稿タイプの保存フックに接続され、`$_POST`が空でなければ旧連載専用の2項目を無条件に参照します。連載CPTにはその旧入力欄がありません。**この保存関数は今回のタイトル・SQLパッチで変更していないことをソース比較で確認しました。** 先に直した空IDのSQLとは別の問題です。

停止時点でSQLエラー・Fatal／Parse errorは0件でしたが、対象旧プラグインから新たなWarningを検出したため停止条件を適用しました。**標準プレビューのクリック確認は、その前の下書き保存で止めたため未実施です。** 通常記事・連載記事の標準プレビュー、再編集、重複拒否、PC／スマートフォン表示を完了したとは扱いません。
