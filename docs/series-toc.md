# 記事内の連載目次

記事冒頭の連載ラベルは従来どおりです。末尾のナビゲーションは、公開済みの全回と、予告を許可した公開予定日を回番号順に表示する目次になりました。現在の記事はリンクを付けず「この記事」と表示します。

## 配置方法

WordPressの記事編集画面で「連載ナビゲーション」ブロックを挿入し、LINE・店舗案内などの前へ移動してください。入力項目はなく、保存済みの連載所属と回番号から自動表示します。

- ブロックがある記事は、その位置へ1回だけ表示します。重複した配置枠は表示しません。
- ブロックがない連載記事は、従来どおり本文全体の後に表示します。
- 連載に所属しない記事や、連載本体が未公開の公開画面には表示しません。
- 予約中の記事で「予約中に回番号と公開予定日時を表示してよい」を有効にすると、回番号と日本時間の公開予定日だけを表示します。正式タイトル・本文・URL・画像は出しません。
- 日時だけでリンクを有効にしません。公開・全件ビルド後に公開記事のリンクへ切り替わります。

## 実装範囲

本文を分割せず、WordPressContentのShadow DOM内の配置枠へ、通常のReact目次をネイティブslotで投影します。既存の本文用CSS、商品スクリプト、LINE・店舗情報を保持します。目次の行データと配置枠の判定は、Reactと静的HTML生成で共有します。

公開記事は既存の連載GraphQLフィールドと全件生成済みの公開データを利用します。署名プレビューは公開済み回と許可済み予告を追加し、12時間の署名と回遊時の期限引き継ぎを維持します。データベース項目・デプロイ基盤は追加しません。

CMSの対象は`ojl-series.php`、`ojl-series-preview.php`、新規`ojl-series-navigation-block.php`、新規`ojl-series/navigation-block.js`です。予約記事を直接削除した場合にも、既存の全件ビルドへ公開連載の予告削除を通知します。

## 検証

```bash
npm test
npx tsc --noEmit
php wp-content/mu-plugins/tests/series-navigation-block.php
php wp-content/mu-plugins/tests/series-preview-expiry.php
```

PHPの検証はCMSリポジトリで実行します。公開・プレビュー・静的HTMLの配置、予告の非リンク表示、現在の記事、重複枠、未所属記事、既存の本文スクリプトとPC・スマートフォン表示を確認してください。
